# Bali Circle

Рабочий прототип партнёрской платформы для бизнеса и блогеров на Бали.

## Попробовать

**[Открыть демо](https://worker14289601.github.io/bali-circle/)**

1. Откройте «Партнёрскую ссылку» на главном экране.
2. Оставьте заявку с вымышленным именем и контактом, например `test@example.com`.
3. Вернитесь в кабинет бизнеса, откройте заявку и подтвердите тестовую оплату.
4. В разделе «Выплаты» запишите демо-перевод с любым тестовым номером.
5. Переключитесь на «Блогер · Лео на Бали» через аватар справа вверху.

Профили бизнеса, блогера и администратора доступны без пароля для знакомства с продуктом. Внизу страницы можно начать демо заново.

**Версия на GitHub Pages хранит данные только в вашем браузере.** У разных посетителей собственные заявки и выплаты; общей серверной базы в этой версии нет. Демо-профили не являются системой безопасной авторизации. Используйте только вымышленные контакты. Визовое агентство, коворкинг, предложения и клиенты — примеры. Сервис не отправляет сообщения и не переводит деньги.

## Возможности

- Создание предложений с фиксированным вознаграждением в IDR.
- Персональные ссылки со случайным кодом без имени партнёра и публичная форма заявки.
- Кабинеты бизнеса, блогера и администратора.
- Поиск, фильтры, карточка заявки и история действий.
- Подтверждение оплаты, начисление комиссии, отмена заявки.
- Учёт переводов, проверка изменившейся суммы, защита от повторных записей.
- Экспорт CSV и адаптивный интерфейс.

## Локальная версия с сервером

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:4173`. Локальная версия использует Express и SQLite, сохраняет данные в `data/bali-circle.sqlite` и разделяет доступ к данным на сервере. По умолчанию она слушает только `127.0.0.1`.

```sh
npm test
npm run build
npm start
```

`PORT` и `DB_PATH` позволяют выбрать порт и расположение базы. Настоящая авторизация пользователей, публичный API, ограничение частоты запросов, уведомления и интеграция с оплатами потребуются перед использованием с реальными клиентами. Демо-вход нельзя выставлять в интернет как рабочую систему доступа.

## Сборка для GitHub Pages

```sh
npm run build:pages
npm run preview:pages
```

Предпросмотр: `http://127.0.0.1:4174/bali-circle/`. Сборка находится в `dist-pages/`; hash-маршруты позволяют открывать предложения напрямую и перезагружать страницы на статическом хостинге.

GitHub Actions запускает проверки, собирает статическую версию и публикует её при обновлении `main`. Сервер, SQLite, сессии и локальные тестовые данные в публикацию не входят.

## Стек и проверка

React 19, TypeScript, Vite, Lucide, Express 5, SQLite. 22 поведенческих теста покрывают API и браузерный адаптер. Основной сценарий дополнительно проверяется во встроенном браузере.
